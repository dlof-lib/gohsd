# GOHSD

تطبيق أندرويد **مجاني بالكامل ومفتوح المصدر** (MIT) — بدون إعلانات ولا اشتراكات ولا تتبّع.
مبني بـ Kotlin + XML، يدعم **Android 15** (minSdk 26، targetSdk 35)، ومصمم للهاتف (عمودي).

## الميزات
- تغيير اسم الشبكة وكلمة السر، وعدد المشتركين وقائمة الأجهزة.
- استهلاك كل جهاز لحظياً، حظر/طرد/تسمية الأجهزة، حظر تلقائي للأجهزة الجديدة.
- إشعار فوري عند اتصال جهاز غير معتمد، تحسين الواي فاي، إعادة تشغيل الراوتر.
- OpenWrt: إدارة أصلية كاملة. V-Link: لوحة الويب + أداة التشخيص (الإدارة الأصلية قيد الإضافة).

## البناء من الهاتف فقط
1. ارفع المشروع إلى مستودع GitHub من الموقع/التطبيق.
2. Actions → Android CI/CD → Run workflow.
3. نزّل ملف APK من Artifacts وثبّته.

## الرابط
`HOME_URL` في `gradle.properties` (الافتراضي https://openwrt.org).

## توقيع release (اختياري)
Secrets: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
